# 📝 Notepad Clone

A desktop text editor built in Java using Swing, replicating the core functionality of Windows Notepad.

## Features
- Create, open, save, and edit text files
- Font and text formatting options
- Find and replace functionality
- Keyboard shortcuts

## Tech Stack
- Java, Java Swing

## How to Run
1. Clone the repository
2. Open in any Java IDE (IntelliJ / Eclipse)
3. Run the `NotepadClone.java` file
